# Manufacturing System

Production management system, built first for Crown Manufacturing Company (egg trays and water jar covers). It runs the production chain from a customer receipt to finished goods, records the factory floor in real time, and reports to the owner and to finance.

## Documents

- [docs/process.md](docs/process.md): how the factory works and what the system must do
- [docs/implementation-plan.md](docs/implementation-plan.md): stack, data model, milestones and testing

## Status

Planning is complete. Milestone 1 (foundation) has not started.

## Stack

Go API, PostgreSQL, React + TypeScript web app, hosted on one cloud server. The interface is in English and Amharic and works on phones, tablets and desktops. Setup instructions will be added with the first milestone.
